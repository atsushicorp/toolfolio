# CSV自動整形ツール

##　概要

このツールは、csvファイルを読み込み、
指定した条件に従ってデータを加工するpythonプログラムです。

## 主な機能

- 不要な列の削除
- 条件に一致する行の抽出
- 文字列の前後空白
- 年齢による昇順ソート
- CSVファイルへの保存

## 動作環境

- Python 3.13
- pandas

## サンプルデータについて

本リポジトリに含まれるinput_sapmle.csvの氏名及びその他のデータは、動作確認のために作成した架空の情報です。

実在する個人・団体とは関係ありません。

本ツールは学習及びポートフォリオ公開を目的として作成しています。

## インストール方法

Python 3.13をインストールした環境で、以下を実行してください。
```powershell
cd python
python -m pip install -r requirements.txt
```

実行すると、`imput_sample.csv`を読み込み、
加工結果を`output.csv`に保存します。

## 注意事項
- `output.csv`が既に存在する場合は、上書きせずに終了します。
- 再実行する場合は、既存の`output.csv`を移動または削除してください。
- 入力CSVはUTF-8形式を想定しています。
